# Third-party components and source material

## R. Loew Electronics

Rudolph R. Loew wrote the Windows 95/98/SE/Me RAM Limitation Patch and SPLIT8MB. His family maintains the public archive containing the professional 7.2 release, the patch generator source and accompanying material. The two DOS components in the packed module inventory retain their original bytes. The original license, manual, readme and change history are provided in this directory tree. Consult the original terms when redistributing code from the archive. [Family archive](https://rloewelectronics.com/) · [PRO 7.2 distribution and source](https://rloewelectronics.com/distribute/PATCHMEM/PRO7.2/) · [Original license](reference/LICENSE.TXT) · [Original manual](reference/MANUAL.TXT)

## HimemX2

The XMS driver distributed in the installation as HIMEMX.EXE is the HimemX2 variant by Japheth, derived from FreeDOS Himem. Till Gerken and Tom Ehlert hold the underlying FD Himem copyrights. The upstream readme describes GPL and/or Artistic licensing for FD Himem and places the HimemX changes in the public domain. The assembly source, upstream build files and both license texts accompany the binary module. [Source and upstream readme](himemx/Readme.txt) · [GPL version 2](himemx/GPL-2.txt) · [Artistic license](himemx/Artistic.txt) · [Upstream project](https://github.com/Baron-von-Riedesel/HimemX)

## Guest systems and tools

MS-DOS, Microsoft Windows, Program Manager and MS-DOS Executive are names of Microsoft products. Catalog records apply byte changes to matching files supplied by the owner of the installation. Screenshots and log records came from QEMU guests. Open Watcom, NASM, QEMU, Ghidra and REA are external development or verification tools. [Open Watcom](https://github.com/open-watcom/open-watcom-v2) · [NASM](https://www.nasm.us/) · [QEMU](https://www.qemu.org/) · [Ghidra](https://github.com/NationalSecurityAgency/ghidra) · [REA](https://github.com/morluto/REA)
