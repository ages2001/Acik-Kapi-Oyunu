Legacy Direct3D device draws and render-target readback

wxold3d.exe loaded the application-local ddraw.dll and requested the HAL device through each historical API. WINOGL supplied a software GL backend. For each device, the probe first read every pixel of a freshly cleared 32 by 32 RGB render target. It submitted three pretransformed vertices, ended the scene, then locked the render target and verified 153 foreground pixels in the interior and 618 preserved background pixels outside the triangle. Samples immediately adjacent to triangle edges are omitted from the second comparison to allow each rasterizer's edge convention.

The Direct3D 1 path submits an execute buffer containing PROCESSVERTICES, STATERENDER, TRIANGLE and EXIT instructions. The Direct3D 2 path uses DrawPrimitive with D3DVT_TLVERTEX, while Direct3D 3 and 7 use a flexible vertex format. Each run below finished with process exit code zero.
