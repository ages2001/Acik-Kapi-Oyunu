## Driver measurements

The native control returns signature 0x574B and the attached filter returns 3. An overlapped request returned error 997 on submission and later completed with four bytes. The QEMU pci-testdev at 1b36:0005 counted two writes to its assigned I/O BAR. The private bus exercised start, stop, restart, D3/D0 and removal. A common-buffer test connected a native NT SYS to QEMU's EDU bus-master device at PCI slot 5. On NT 3.1, 3.50, 3.51 and 4.0 the same driver allocated an 8,192-byte buffer through the legacy HAL. It wrote 4,096 bytes from its first half to the device, cleared the source, then read the device into the second half. Every byte matched an independent pattern. All four guests returned FNV-1a 0x103909c5. [DMA measurements](evidence/nt-edu-dma.txt) · [QEMU EDU specification](https://www.qemu.org/docs/master/specs/edu.html)

The reconstructed VHD passed its ZIP CRC, and the installed KERNEL32 and USER32 both identified 4.10.1998. Six independent disk copies passed the target checks.
