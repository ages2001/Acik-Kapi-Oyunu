QEMU 10.0.13, Pentium, IDE system disk, pci-testdev and lsi53c810.
The 53C810 had a separate, read-only, partitioned FAT16 SCSI disk at ID zero.
The disk held a 65,536-byte file NCRTEST.BIN; its bytes were generated outside the guest.
Original test file SHA-256 7ce811f72f73b348d733ce482442f1d114a378c48cc8a83c87a34d4ea813eaf8

The guest copied the unchanged OEM image as System32\drivers\NcrWdmQa.sys and
registered it under a private boot-start service in the SCSI miniport group.
Each run queried the service after restart and attempted to read the test file
through the mounted filesystem. WINWDM 6.0 was installed in the same guest.
This exercises the native NT SCSIPORT miniport interface. The binary imports
14 SCSIPORT functions. This experiment does not exercise WDM PnP or PortCls.
