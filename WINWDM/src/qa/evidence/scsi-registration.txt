SCSIPORT miniport registration on original Microsoft x86 Windows NT, QEMU TCG.
WKS064 and WKS076 call the system directly with 64 and 76 bytes. The SDK probes
supply 80 bytes. WKSADPT uses ISA without extensions, WKSPCI matches 1000:0001,
and WKSCTRL provides an adapter-control callback. All probes decline hardware.
STATUS_DEVICE_DOES_NOT_EXIST (0xC00000C0) after one callback is expected.
STATUS_REVISION_MISMATCH (0xC0000059) with zero callbacks rejects registration.

The NCR NT 3.5 miniport sets HwInitializationDataSize to 76 and supplies PCI vendor
and device ID strings. The NT 3.1 SCSIPORT initialization routine compares the size
with 64 and returns STATUS_REVISION_MISMATCH on a size mismatch. NT 3.51 accepts
the NCR descriptor. The independent probes vary the size on the same native bus.
All variants run through the guest boot loader and its unmodified SCSIPORT.
