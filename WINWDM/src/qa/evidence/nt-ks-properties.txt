Native x86 Kernel Streaming properties and format intersection on QEMU 10.0.13 and Microsoft NT.
One separately linked SYS imports KsPinPropertyHandler, KsTopologyPropertyHandler and KsPinDataIntersection by name from KS.SYS.
The client allocates an IRP with the native I/O manager and supplies captured inputs and system-mapped output as in a KS property callback.
Both images have 4096-byte alignment and local memory routines for NT 3.1.
The tests cover seven static pin properties, three topology properties and their length, padding and ownership contracts.
The minidriver callback negotiates stereo 16-bit PCM at 48000 Hz. A non-PCM candidate never reaches it.
It rejects 44100 Hz and accepts the next candidate. Tests also cover caller and factory wildcard GUIDs,
size queries, truncated data, unsupported attributes, callback stack convention and short output.
These kernel requests negotiate a format. They do not open a streaming pin or submit media packets.
