Native x86 Kernel Streaming verification on QEMU 10.0.13 and Microsoft NT.
The independently linked WKKS.SYS imports five functions from WINWDM KS.SYS. Each system opened the native QA filter from Win32.
KsPinPropertyHandler and KsTopologyPropertyHandler handled seven pin properties and three topology queries.
KsPinDataIntersection called the separately linked miniport callback and negotiated 48 kHz, 16-bit stereo PCM.
KsCreatePin submitted real relative IRP_MJ_CREATE requests. KsValidateConnectRequest returned a pool-owned copy of the negotiated format.
The filter rejected 44.1 kHz and an invalid pin ID. Two successful creates returned separate native render and capture handles.
The kernel client tried a write while stopped, set ACQUIRE, PAUSE and RUN, submitted IOCTL_KS_WRITE_STREAM, then IOCTL_KS_READ_STREAM.
All 512 PCM bytes matched through the QA filter's software loopback. Its packet dispatch accepts kernel-mode callers.
Hardware playback on pre-WDM NT and general-purpose user-mode stream transport remain open.
