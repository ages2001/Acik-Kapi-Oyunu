Original Microsoft x86 NT kernel driver loader, QEMU 10.0.13 TCG, one Pentium CPU.
Eight images use the same compiled entry.o and only import NTOSKRNL!RtlInitUnicodeString.
Each image prints its own service name to the QEMU debug console from DriverEntry,
creates no device and deliberately returns STATUS_NO_SUCH_DEVICE (StartService error 20).
Error 193 is ERROR_BAD_EXE_FORMAT. No service was left installed.

Original WDMHDA 0.26 HDA.SYS uses OS version 5.0, native subsystem version 5.0,
32-byte file and section alignment. The original binary returned 193 on NT 3.1.
Changing the version fields in these independent controls had no effect on entry.
The separate HDA import check found missing native services and the PortCls module.
No HDA or Microsoft binary was changed in this experiment.
