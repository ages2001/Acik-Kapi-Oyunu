Native x86 PortCls resource and interrupt verification on QEMU 10.0.13 with EDU 1234:11e8 in slot 5.
Each guest started and stopped the provider and independent client with its native Service Control Manager.
PcNewResourceList copied paired bus-relative and system resources. The test overwrote the original descriptors.
PcNewResourceSublist copied entries in a new order and retained the corresponding raw port for a translated memory descriptor.
The client checked counts, interface references, invalid index, capacity, parent release and the translated EDU line interrupt.
PcNewInterruptSync handled Normal, All and Repeat dispatch on that line. PcGetTimeInterval measured native 100 ns time.
The independent DMA test wrote 4096 bytes to the device and read all bytes back. All interrupts were acknowledged.
