Microsoft SETUP installed the six disks onto a new, empty FAT16 disk. MS-DOS 5.0 booted from A:.
File Manager About displayed "Version 3.11" and "386 Enhanced Mode". The standalone WINVER utility displayed 3.10.
The volume labels were MSWIN3111 through MSWIN3116. Installed file sizes and SHA-256 values follow.

KRNL386.EXE  76400 bytes  b2686eb8882e251e00471a9c7a43b365390800c8ccffda9fd7e7eb1141cfea2e
USER.EXE  264016 bytes  58e75f618d1d60f16bcc1be669a3e475b61f5af08a37347a8aa032af63c5d473
GDI.EXE  220800 bytes  928b30373155e71219715cb961952b9ec4e158ec88a74a57b6280ffa550b37b5
KRNL386.EXE and GDI.EXE matched the decompressed distribution files. Setup recorded the registered user in USER.EXE.

Each test started with its own copy of the installation. W16CHECK operated the actual Setup wizard.
Windows restarted before the live VxD test. The Info and Uninstall executable hashes matched the distribution.
