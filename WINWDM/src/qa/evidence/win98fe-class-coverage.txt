Symbols from the installed development kit are x86 NT test providers. They are not installed over the Win9x system files.
The First Edition reference describes that release only. Export counts are not a WDM conformance percentage.

The Win3.x and Win9x VxD links the project function driver at build time. A general independent PE WDM loader remains open.
First Edition used its original NTKERN for the audio, hub and keyboard tests. The native NT pin test opened two real handles and looped back a packet through a QA filter. Hardware playback on pre-WDM NT, the PortCls wave port and general streaming transport remain open.
