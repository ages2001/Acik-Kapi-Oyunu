Comparison against the original Windows 98 First Edition installation cabinets, build 4.10.1998.
Symbols from the installed development kit are x86 NT test providers. They are not installed over the Win9x system files.
The First Edition reference describes that release only. Export counts are not a WDM conformance percentage.

The Win3.x and Win9x kit VxD links the project function driver at build time. The independent PE WDM loader from NTKERN.VXD has not been ported.
The Windows 98 FE USB audio and hub tests exercised the original system loader. On native NT the kit negotiates formats through a minidriver callback. A pin factory, PortCls wave port and packet transport remain unimplemented.
